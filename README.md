# Mia-Ai v2

Локальная архитектура двух ИИ-агентов: Мия и Эдит.

## Архитектура

- `index.html` — точка входа
- `interface/` — интерфейс
- `core/` — восприятие, контекст, рассуждение, планирование
- `brains/mia/` — отдельный мозг Мии
- `brains/edith/` — отдельный мозг Эдит
- `memory/` — память и отношения
- `learning/` — обучение и исправления
- `communication/` — диалог Мии и Эдит
- `tools/` — локальные инструменты
- `world/` — базовые знания

Проект работает как статический сайт без GPT, Ollama и API.
Память в браузере хранится через localStorage.

Важно: это когнитивная архитектура, а не обученная языковая нейросеть человеческого уровня.
